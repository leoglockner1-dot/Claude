# Reward Presentation and Perceived Value

How presentation changes perceived value (synthesis):
| Lever | Evidence | Guidance |
|---|---|---|
| Size & isolation | Dragon Adventures hero bundle ([UI-05](../01-UI-UX/Analyses/UI-05-Dragon-Adventures-Premium-Shop.md)) | Space and scale signal value more than badges |
| Art scales with quantity | Same | Coin stack → vault |
| Rarity colour + tag | TDS, BotClash | Consistent rarity ladder across UI/VFX/audio |
| Anticipation | Trap telegraph ([V20](../16-Video-Analyses/V20-Burst-Particle-Trap.md)) | Build-up before rare reveals |
| Travel to counter | Winds of Fortune coins (GF-01) | Show where value went |
| Sound brightness | Victory vs defeat timbre (V08/V09) | Brighter = better |
| Text claims | "0.0001 %" bait (TI-15) | Must be true and consistent |
