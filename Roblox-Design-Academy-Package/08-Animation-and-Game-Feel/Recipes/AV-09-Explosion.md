# AV-09 — Explosion

| Step | Specification |
|---|---|
| **Trigger** | Server-confirmed detonation (bomb, barrel, ability). |
| **Timing** | Flash 1–2 frames → fireball 0.2–0.4 s → smoke 1–2 s; burst peak measured ≈0.4 s in the official burst-trap video. |
| **Anticipation** | Fuse/blink accelerating, or a ground telegraph ring 0.5–1 s before. |
| **Main action** | Fireball expansion + debris. |
| **Impact** | Flash + low boom + camera shake scaled by distance. |
| **Follow-through** | Smoke rises and fades; scorch decal briefly; debris settles. |
| **Sound** | Layered: transient crack + low boom + debris tail; distance-attenuated (3D). |
| **Visual hierarchy** | Danger radius must be readable *before* it goes off (telegraph), not only after. |
| **Performance considerations** | Burst with `Emit(n)` not Rate; cap simultaneous explosions; scale particle counts by device. |
| **When restraint is preferable** | Small/frequent explosions: drop the smoke and shake. |
| **Roblox implementation** | `Explosion` instance or custom; damage resolved on the server; VFX on clients from one event. |
| **Evidence and previews** | [V20 burst trap](../../21-Video-Analyses/V20-Burst-Particle-Trap.md); [LU-19](../../07-Roblox-Studio-and-Luau/LU-19-VFX-System.md); explosion tutorial (use-particles-for-explosions, Roblox docs). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
