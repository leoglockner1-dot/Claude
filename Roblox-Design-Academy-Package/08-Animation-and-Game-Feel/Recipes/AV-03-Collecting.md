# AV-03 — Collecting (coins, gems, pickups)

| Step | Specification |
|---|---|
| **Trigger** | The server confirms a pickup (or the client predicts it and the server reconciles). |
| **Timing** | Burst 0.4–0.5 s, then home to the counter over 0.3 s (Cubic Out), staggered 20 ms per coin; the counter ticks per arrival. |
| **Anticipation** | Pickups idle-bob/spin to be noticed (0.8–1.2 s loop). |
| **Main action** | Burst outward with varied speeds and sizes. |
| **Impact** | Each coin hitting the counter: counter pulse (+8% scale) + tick. |
| **Follow-through** | Counter settles; a streak indicator if pickups chain. |
| **Sound** | Bright ding 80–200 ms; **pitch steps up per pickup in a streak** (preview: +1 semitone per pickup, 110 ms apart); cap simultaneous plays. |
| **Visual hierarchy** | Currency colour is reserved for currency; the counter is the destination users learn to watch. |
| **Performance considerations** | Pool the coin visuals; cap the burst to 10–20; on Small viewports halve the count. |
| **When restraint is preferable** | Very frequent pickups (hundreds per minute): skip the burst, keep the counter tick and sound. |
| **Roblox implementation** | Server validates pickups (distance, rate) before granting ([LU-05](../../07-Roblox-Studio-and-Luau/LU-05-Server-Validation.md)); client plays VFX from a pool ([LU-19](../../07-Roblox-Studio-and-Luau/LU-19-VFX-System.md)). |
