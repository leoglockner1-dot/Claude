# AV-07 — Rare reward reveal

| Step | Specification |
|---|---|
| **Trigger** | The server resolves a roll (egg, crate, gacha) with a rarity tier. |
| **Timing** | Anticipation 1.2 s → impact 0.15 s → follow-through ~1 s; **input unblocked at ~1.6 s; skippable after the first time**. Common tiers get shorter versions (0.3–0.6 s). |
| **Anticipation** | Crate shakes with increasing frequency, glow builds in the rarity colour, riser pitch climbs (preview riser 220→880 Hz). |
| **Main action** | Burst open; the item scales in with Back Out. |
| **Impact** | Low impact hit + sparkle at exactly the reveal frame (preview impact onset measured at 1.200 s). |
| **Follow-through** | Item settles, name + rarity label, odds tier shown; collection index updates. |
| **Sound** | Riser → impact → sparkle, with a per-rarity motif. |
| **Visual hierarchy** | Rarity colour language must be consistent everywhere (UI, VFX, item frames). |
| **Performance considerations** | One-shot emitters, pooled; fewer particles on phones. |
| **When restraint is preferable** | Never fake near-misses that misrepresent odds; for paid rolls, odds disclosure rules apply ([LU-13](../../07-Roblox-Studio-and-Luau/LU-13-Random-Rewards.md)). |
| **Roblox implementation** | Roll on the server ([WeightedLoot](../../07-Roblox-Studio-and-Luau/LU-13-Random-Rewards.md)); the client plays the sequence from the result; show effective odds when pity applies. |
