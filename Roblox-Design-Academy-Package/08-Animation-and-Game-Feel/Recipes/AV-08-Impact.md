# AV-08 — Impact (light and heavy hits)

| Step | Specification |
|---|---|
| **Trigger** | A hit is confirmed (client-predicted cosmetic, server-confirmed damage). |
| **Timing** | Light: 80–150 ms total (preview 90 ms). Heavy: 200–400 ms (preview v1 0.43 s **over spec** → v2 0.35 s); hit-stop 0.03–0.08 s locally on heavy hits only. |
| **Anticipation** | Attack wind-up on the attacker (telegraph) 0.15–0.4 s depending on weight. |
| **Main action** | Target flinch/knockback; hit spark at the contact point. |
| **Impact** | Hit spark + sound + (heavy) brief hit-stop and camera kick. |
| **Follow-through** | Damage number floats up and fades 0.6 s; target recovers. |
| **Sound** | Light: short transient with material texture, rotate 3–4 variants. Heavy: low thump + crack + short tail. |
| **Visual hierarchy** | Confirmed hits must be distinguishable from blocked hits (different colour and sound). |
| **Performance considerations** | Pool sparks; limit damage numbers on screen (merge rapid hits). |
| **When restraint is preferable** | Rapid-fire weapons: smaller per-hit feedback; save the heavy treatment for kills/crits. |
| **Roblox implementation** | Server validates hits ([LU-03](../../07-Roblox-Studio-and-Luau/LU-03-Client-Server-Responsibilities.md)); the client plays local hit-stop (never freeze the server). |
