# AV-01 — Button feedback

| Step | Specification |
|---|---|
| **Trigger** | Pointer/touch down on a button (`Activated` for the click; `InputBegan`/`MouseButton1Down` for the press visual). |
| **Timing** | Press 0.06–0.08 s to scale 0.94 (Quad Out); release 0.10–0.15 s with Back Out (≈ +0.6% overshoot here). Preview measured: min scale 0.940, max 1.006. |
| **Anticipation** | Hover (desktop only): +3% scale or brightness over 0.08 s. None on touch. |
| **Main action** | Scale dip on press. |
| **Impact** | Release pop + click sound on the press frame. |
| **Follow-through** | Button returns to rest; any result (purchase) shows separately when the server answers. |
| **Sound** | Soft pop 60–120 ms, mid-high (preview: 70 ms, centroid ≈1.5 kHz), ±3% pitch variation. |
| **Visual hierarchy** | Primary buttons get the strongest feedback; secondary buttons subtler; disabled buttons give a short "denied" nudge instead (AV-05). |
| **Performance considerations** | Tween `UIScale`, not Size (no layout reflow); reuse one tween per button. |
| **When restraint is preferable** | List rows and dense grids: colour change only; motion on every row is noise. |
| **Roblox implementation** | `TweenService:Create(uiScale, TweenInfo.new(0.07, Enum.EasingStyle.Quad, Enum.EasingDirection.Out), {Scale = 0.94})`; release with `Enum.EasingStyle.Back`. Sound through the UI SoundGroup ([LU-18](../../07-Roblox-Studio-and-Luau/LU-18-Sound-System.md)). |
| **Evidence and previews** | Preview GIF ([AV-01_button_press.gif](../../Assets/Original/AV/AV-01_button_press.gif)), sound ([wav](../../Assets/Original/AV/AV-01_button_press.wav), [waveform](../../Assets/Original/AV/AV-01_button_press-waveform.jpg)); same-frame UI sound in official video [V16](../../21-Video-Analyses/V14-V17-Pickup-and-UI-Sounds.md); [R12](../../18-Skill-Training/Design-Recipes/R12-Reusable-Button-Animation-System.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
