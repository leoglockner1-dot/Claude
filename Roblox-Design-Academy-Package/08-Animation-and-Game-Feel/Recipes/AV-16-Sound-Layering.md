# AV-16 — Sound layering

| Step | Specification |
|---|---|
| **Trigger** | Any important event that needs weight. |
| **Timing** | Layers aligned on the event frame; transient first (0–20 ms), body (20–200 ms), tail (200 ms+). |
| **Anticipation** | Optional pre-roll layer (whoosh) 50–150 ms before impact. |
| **Main action** | Combine transient (click/crack) + body (tone/thump) + tail (reverb/debris). |
| **Impact** | The transient defines the perceived timing; align it exactly with the visual. |
| **Follow-through** | Tail lets the moment breathe; shorten it for frequent events. |
| **Sound** | See the heavy impact preview: thump + crack + tail. Each layer occupies a different frequency band. |
| **Visual hierarchy** | Important events get more layers; frequent ones fewer. |
| **Performance considerations** | Each layer is a Sound instance; reuse; limit polyphony. |
| **When restraint is preferable** | Don't layer everything: mud. Keep UI sounds single-layer. |
| **Roblox implementation** | Multiple Sounds in one Attachment, played together; or the audio API mixing. |
| **Evidence and previews** | Heavy impact preview ([waveform](../../Assets/Original/AV/AV-08_impact_heavy-waveform.jpg)) shows three layers; [Sound Design Principles](../../10-Sound-Design/Sound-Design-Principles.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
