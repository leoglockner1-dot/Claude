# AV-05 — Error / denied action

| Step | Specification |
|---|---|
| **Trigger** | Server refuses (insufficient funds, too far) or the action is unavailable. |
| **Timing** | Horizontal shake 3 × 6 px over 0.25 s; the reason text appears within 0.1 s and stays ~2 s. |
| **Anticipation** | None. |
| **Main action** | Shake + red-tinted outline. |
| **Impact** | Muted low thud (preview: 160 ms, spectral centroid ≈300 Hz). |
| **Follow-through** | Point to the fix ("Need 40 more coins", with a link to how to earn). |
| **Sound** | Short, low, soft; never harsh or loud. |
| **Visual hierarchy** | The reason text is the hero, not the animation. |
| **Performance considerations** | Trivial. |
| **When restraint is preferable** | Don't use error feedback for normal state (a disabled button shouldn't scream every press: shake once, then just show the tooltip). |
| **Roblox implementation** | Return a reason string from the server handler; the client maps reason → message. |
| **Evidence and previews** | Sound ([wav](../../Assets/Original/AV/AV-05_error_denied.wav), [waveform](../../Assets/Original/AV/AV-05_error_denied-waveform.jpg)); [Sound Recipes](../../10-Sound-Design/Sound-Recipes.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
