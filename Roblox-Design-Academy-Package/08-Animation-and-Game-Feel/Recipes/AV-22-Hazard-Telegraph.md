# AV-22 — Hazard telegraph and warnings

| Step | Specification |
|---|---|
| **Trigger** | A hazard will activate (trap, boss attack, falling rocks). |
| **Timing** | Telegraph 0.4–1.0 s before activation (shorter = harder); pulse rate increasing toward activation. |
| **Anticipation** | This *is* the anticipation: ground ring, glow, sound pulse. |
| **Main action** | Hazard fires exactly when the telegraph completes. |
| **Impact** | Activation flash + sound. |
| **Follow-through** | Short cooldown visible (hazard dims). |
| **Sound** | Rhythmic pulse increasing in rate; must have a visual twin. |
| **Visual hierarchy** | Telegraph colour reserved for danger; consistent across the game. |
| **Performance considerations** | Decals/rings are cheaper than particles for telegraphs. |
| **When restraint is preferable** | Don't telegraph *everything*; ambient hazards with constant patterns can rely on learned rhythm. |
| **Roblox implementation** | The server schedules the hazard; clients play the telegraph from the same timestamp (send start time, not "now"). |
| **Evidence and previews** | [FEEL-001 Telegraph before payoff](../../17-Design-Principles/Game-Feel-Principles.md); [V20](../../21-Video-Analyses/V20-Burst-Particle-Trap.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
