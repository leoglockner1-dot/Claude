# AV-19 — Camera movement (shake, kick, follow)

| Step | Specification |
|---|---|
| **Trigger** | Heavy impacts, explosions, speed changes, cinematic moments. |
| **Timing** | Shake 0.1–0.3 s decaying; FOV kick 0.08 s in / 0.25 s out; follow springs ω 4–8. |
| **Anticipation** | None for shake; slight push-in before reveals. |
| **Main action** | Translational noise (not rotation) for shake; FOV for speed. |
| **Impact** | Strength scales with event size and distance. |
| **Follow-through** | Decays smoothly; never ends with a jerk. |
| **Sound** | Shake pairs with low-frequency sound. |
| **Visual hierarchy** | Camera effects for the *local player's* important events only. |
| **Performance considerations** | Trivial CPU; the cost is readability and comfort. |
| **When restraint is preferable** | Default to none; provide a "reduce camera shake" setting; avoid shake on frequent actions. |
| **Roblox implementation** | Client RenderStepped offset on Camera.CFrame; respect a settings toggle. |
| **Evidence and previews** | [AP-15 unnecessary camera shake](../../15-Anti-Patterns-and-Failure-Cases/Anti-Pattern-Catalog.md); [Game-Feel Principles](../../17-Design-Principles/Game-Feel-Principles.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
