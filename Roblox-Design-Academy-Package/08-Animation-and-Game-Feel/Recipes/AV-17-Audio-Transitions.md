# AV-17 — Audio transitions (music states, crossfades, ducking)

| Step | Specification |
|---|---|
| **Trigger** | Game state change (lobby → round → results), area change, important UI. |
| **Timing** | Crossfade music 1–2 s between states; duck music 20–40% for 0.5–1.5 s under important cues. |
| **Anticipation** | Stinger or riser 1 s before a round starts. |
| **Main action** | Crossfade/duck. |
| **Impact** | New state music lands on a downbeat if possible. |
| **Follow-through** | Restore volumes smoothly (0.3–0.5 s release). |
| **Sound** | Music per state; consistent loudness between tracks. |
| **Visual hierarchy** | Voice/critical cues > SFX > music. |
| **Performance considerations** | Keep few music Sounds loaded; stream long tracks. |
| **When restraint is preferable** | Rapid state flips: don't restart music each time; keep a continuous bed. |
| **Roblox implementation** | SoundGroups + CompressorSoundEffect side-chain for ducking ([LU-18](../../07-Roblox-Studio-and-Luau/LU-18-Sound-System.md)); a music controller listens to RoundMachine onEnter. |
| **Evidence and previews** | Roblox sound groups doc (ducking); [Measured Audio Observations](../../10-Sound-Design/Measured-Audio-Observations.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
