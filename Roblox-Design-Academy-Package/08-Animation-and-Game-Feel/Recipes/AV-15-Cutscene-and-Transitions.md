# AV-15 — Cutscenes and scene transitions

| Step | Specification |
|---|---|
| **Trigger** | Story beat; teleport; chapter start. |
| **Timing** | Black hold ≈1.2 s then blur→focus ≈1.3 s (official Duvall Drive transport); respawn fade ≈0.7 s. |
| **Anticipation** | Letterbox bars slide in 0.3 s to signal "watch now". |
| **Main action** | Camera moves on rails; dialogue/typewriter text (≈10–15 chars/s measured). |
| **Impact** | Key reveal shot held ≥1 s. |
| **Follow-through** | Control returns with a clear objective prompt. |
| **Sound** | Music stinger at the start; ambience continues to bridge cuts. |
| **Visual hierarchy** | Skippable after the first view; never block input for long without a skip. |
| **Performance considerations** | Preload the destination before revealing it (fade covers the load). |
| **When restraint is preferable** | Short sessions/mobile: prefer in-world events over cutscenes. |
| **Roblox implementation** | Camera.CameraType = Scriptable with tweened CFrames; ContentProvider:PreloadAsync behind the fade. |
| **Evidence and previews** | [V21/V22](../../21-Video-Analyses/V21-V22-Duvall-Cutscene-and-Respawn.md); [V26 typewriter](../../21-Video-Analyses/V26-Typewriter-Text.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
