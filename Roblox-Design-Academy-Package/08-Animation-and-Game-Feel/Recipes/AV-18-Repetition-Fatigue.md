# AV-18 — Controlling repetition fatigue

| Step | Specification |
|---|---|
| **Trigger** | Any feedback that fires very often (pickups, footsteps, clicks, hits). |
| **Timing** | Vary per instance; escalate in streaks (pitch +1 semitone per pickup, reset after 1 s gap). |
| **Anticipation** | — |
| **Main action** | Rotate 3–4 variants; ±3–5% pitch; small timing jitter. |
| **Impact** | Streak escalation turns repetition into momentum. |
| **Follow-through** | Reset to base after a pause. |
| **Sound** | Variation pools; streak pitch ladders (coin preview). |
| **Visual hierarchy** | The more frequent the event, the softer its feedback. |
| **Performance considerations** | Variation costs memory (more samples); 3–4 is enough. |
| **When restraint is preferable** | Signature sounds (level-up, legendary) should stay identical, because recognition is the point. |
| **Roblox implementation** | SoundController picks a random variant and sets `PlaybackSpeed` = 1 ± 0.04. |
| **Evidence and previews** | Coin streak ([wav](../../Assets/Original/AV/AV-03_coin_pickup_streak.wav)); [Sound Recipes](../../10-Sound-Design/Sound-Recipes.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
