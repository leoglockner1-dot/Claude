# AV-23 — Performance-aware effects (quality tiers)

| Step | Specification |
|---|---|
| **Trigger** | Effect playback on any device. |
| **Timing** | Same timing on all tiers (timing carries meaning); reduce density, not duration. |
| **Anticipation** | — |
| **Main action** | Tier 1 (phones/low FPS): sprites/decals, half particles, no shadows from effects; Tier 2: full. |
| **Impact** | Keep the impact frame identical across tiers. |
| **Follow-through** | Shorter tails on Tier 1. |
| **Sound** | Unaffected. |
| **Visual hierarchy** | Cut decorative effects first; never cut gameplay telegraphs. |
| **Performance considerations** | Measure with the MicroProfiler and Render Stats on a phone profile ([LU-23](../../07-Roblox-Studio-and-Luau/LU-23-Performance-Profiling.md)). |
| **When restraint is preferable** | If the low tier still reads, consider making it the default. |
| **Roblox implementation** | `GuiService.ViewportDisplaySize`, user graphics quality level and measured frame time choose the tier at runtime. |
| **Evidence and previews** | [VFX Principles and Performance](../../09-VFX/VFX-Principles-and-Performance.md); Roblox performance docs. |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
