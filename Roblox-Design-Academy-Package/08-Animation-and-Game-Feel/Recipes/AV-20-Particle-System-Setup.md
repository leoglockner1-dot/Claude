# AV-20 — Particle system setup and budget

| Step | Specification |
|---|---|
| **Trigger** | Any effect built from ParticleEmitters. |
| **Timing** | Lifetime ranges short (0.3–1.5 s) for gameplay feedback; longer for ambience. |
| **Anticipation** | Telegraph emitters may run at low Rate before a burst. |
| **Main action** | Choose Shape, SpreadAngle, Speed, Size/Transparency curves. |
| **Impact** | Burst via `Emit(n)`. |
| **Follow-through** | Fade out via Transparency curves; avoid hard pops. |
| **Sound** | Match bursts to one sound, not per particle. |
| **Visual hierarchy** | Gameplay-relevant particles bright and short; decorative ones dim and slow. |
| **Performance considerations** | Docs: up to **400 particles/s per emitter (100/s on mobile)**; property changes on emitters can dramatically affect performance; keep Rate low and use Size instead. |
| **When restraint is preferable** | If a static decal or a single sprite communicates the same thing, use that. |
| **Roblox implementation** | Templates in ReplicatedStorage; pooled playback ([LU-19](../../07-Roblox-Studio-and-Luau/LU-19-VFX-System.md)). |
| **Evidence and previews** | [Particles, Lighting and Effects (reference)](../../14-Technical-Reference/Particles-Lighting-and-Effects.md); particle emitter docs. |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
