# AV-06 — Level-up and milestones

| Step | Specification |
|---|---|
| **Trigger** | The player crosses a level/milestone threshold (server-authoritative). |
| **Timing** | 1–2 s total, input **unblocked within ~0.5 s**; preview arpeggio 0.9 s. |
| **Anticipation** | XP bar fills to the end with acceleration in the last 10%. |
| **Main action** | Level number pops (Back Out), radial burst behind it. |
| **Impact** | Arpeggio peak + brief music duck (~30%). |
| **Follow-through** | "New: ___" unlock line(s) that tell what changed (and where to use it). |
| **Sound** | Ascending arpeggio + soft whoosh. |
| **Visual hierarchy** | Unlock information > fireworks. |
| **Performance considerations** | One burst emitter, pooled; skip if many level-ups chain (show the final one). |
| **When restraint is preferable** | Frequent tiny levels: just a counter pulse; save the full moment for meaningful milestones. |
| **Roblox implementation** | Duck music via a CompressorSoundEffect side-chain ([LU-18](../../07-Roblox-Studio-and-Luau/LU-18-Sound-System.md)). |
| **Evidence and previews** | Sound ([wav](../../Assets/Original/AV/AV-06_level_up.wav), [waveform](../../Assets/Original/AV/AV-06_level_up-waveform.jpg)); [R06](../../18-Skill-Training/Design-Recipes/R06-Milestone-Celebration.md). |

**Test:** play it 20 times in a row. Is it still pleasant? Does it still read at phone size? Is the meaning clear with the sound off and with the visuals ignored (sound only)?
