# GM-11 — Risk and reward

| Aspect | Notes |
|---|---|
| **What the player does** | Chooses between a safe outcome and a riskier, bigger one: bank vs push on, steal vs defend, dig while the guard sleeps. |
| **Skill or decision involved** | Judgement under uncertainty; reading odds and opponents. |
| **Feedback needed** | Clear stakes shown before choosing (what you could lose/gain), tension cues during the risk, dramatic resolution. |
| **Why it can be satisfying** | Meaningful decisions create stories; greed and caution are both valid. |
| **Design conditions under which it works** | Losses must be **recoverable** and understood in advance; the risky option must sometimes be right. Paid random items require disclosed odds ([LU-13](../07-Roblox-Studio-and-Luau/LU-13-Random-Rewards.md)). |
| **How difficulty can scale** | Higher stakes, less information, time pressure. |
| **How progression can change it** | Insurance items, information upgrades (seeing odds), bigger jackpots. |
| **What causes repetition fatigue** | One dominant strategy (always bank); losses that feel random. |
| **Exploits and edge cases (Roblox-specific where relevant)** | Leaving the game to avoid a loss (save state carefully); duplicate claims. |
| **Genres it fits** | Steal loops, roguelites, extraction games, gambling-free push-your-luck. |
| **Genres it does not fit (or fits badly)** | Very young audiences sensitive to loss; pure cozy games. |
| **Original variations** | Risk shared by the team (one person's greed endangers all); risk you can see others taking. |
| **Prototype and testing guidance** | Push-your-luck: each step adds reward and a rising failure chance; test whether players vary strategy. |
