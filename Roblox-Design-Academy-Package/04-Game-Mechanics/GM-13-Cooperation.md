# GM-13 — Cooperation

| Aspect | Notes |
|---|---|
| **What the player does** | Works with others toward a shared goal: split roles, combined actions, shared resources. |
| **Skill or decision involved** | Communication, role execution, trust. |
| **Feedback needed** | Shared progress visuals, credit for each role, "together" moments (simultaneous success). |
| **Why it can be satisfying** | Social bonding; stories shared with friends; interdependence feels meaningful. |
| **Design conditions under which it works** | **Design the stranger and solo experience**: fallbacks for AFK/trolls, partner swap, optional rather than mandatory dependence. Evidence: hard dependency co-op obbies have low like ratios (Teamwork Puzzles 49%, Be My Camera 58%) while the physical-tether co-op Webbed sits at 87% [DATA]. |
| **How difficulty can scale** | Tighter coordination windows, more roles, harder puzzles. |
| **How progression can change it** | Team upgrades, unlockable roles. |
| **What causes repetition fatigue** | One player doing everything; waiting for a partner. |
| **Exploits and edge cases (Roblox-specific where relevant)** | Griefing partners (trolling); carrying for paid services. |
| **Genres it fits** | Co-op obbies, survival, jobs (Pizza Place), raids. |
| **Genres it does not fit (or fits badly)** | Strictly solo audiences; games without voice/text-friendly pacing. |
| **Original variations** | Cooperation through a shared vehicle (Dead Rails train); production chains (Pizza Place). |
| **Prototype and testing guidance** | A 2-person puzzle with a solo fallback path; compare enjoyment for friends vs strangers. |
