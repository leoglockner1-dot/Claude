# GM-14 — Competition

| Aspect | Notes |
|---|---|
| **What the player does** | Tries to beat other players: score, survive longer, defeat them. |
| **Skill or decision involved** | Depends: execution, strategy, reading opponents. |
| **Feedback needed** | Live standing (scoreboard), clear win/lose screens, recognition (MVP, titles). |
| **Why it can be satisfying** | Status, mastery, the thrill of outplaying a human. |
| **Design conditions under which it works** | Fairness is the currency: never sell advantages in the deciding skill ([CS-44 Musical Chairs](../20-Game-Case-Studies/CS-44-Musical-Chairs.md), 66% likes with a speed pass); matchmaking or modes to protect new players; server authority. |
| **How difficulty can scale** | Ranked tiers, stronger opponents. |
| **How progression can change it** | Ranks, cosmetics, loadouts with sidegrades (not straight upgrades). |
| **What causes repetition fatigue** | Losing streaks without learning; stomping by veterans; stale metas. |
| **Exploits and edge cases (Roblox-specific where relevant)** | Cheating (aim, speed), teaming in free-for-all, alt accounts. |
| **Genres it fits** | Shooters, fighting, sports, party elimination. |
| **Genres it does not fit (or fits badly)** | Cozy/social roleplay (unless opt-in). |
| **Original variations** | Asymmetric competition (1 vs many); competition through creation (fashion voting in DTI). |
| **Prototype and testing guidance** | 2-player duel with one mechanic; measure rematch rate. |
