# GM-15 — Exploration

| Aspect | Notes |
|---|---|
| **What the player does** | Moves through space to find places, secrets and views. |
| **Skill or decision involved** | Curiosity, navigation, reading environmental cues. |
| **Feedback needed** | New vistas, landmarks, map reveals, discovery stingers (sound), collectible lore. |
| **Why it can be satisfying** | Wonder and autonomy; secrets reward attention. |
| **Design conditions under which it works** | Worlds need landmarks and readable paths ([Environmental Communication](../12-Level-Design/Environmental-Communication.md)); exploration must pay off (lore, shortcuts, rare spawns); streaming/performance for large maps. |
| **How difficulty can scale** | Hidden paths, traversal tools required, hazardous regions. |
| **How progression can change it** | Movement upgrades (boats, gliders) unlocking new regions (Fisch boats, Bee Swarm mountain). |
| **What causes repetition fatigue** | Empty space; backtracking without new information. |
| **Exploits and edge cases (Roblox-specific where relevant)** | Out-of-bounds clipping; teleport exploits (validate positions). |
| **Genres it fits** | Adventure, RPG, simulators with zones, horror. |
| **Genres it does not fit (or fits badly)** | Short competitive rounds. |
| **Original variations** | Exploration that changes the world permanently for the server; explore through someone else's eyes (Be My Camera). |
| **Prototype and testing guidance** | Small island with 3 secrets and 1 landmark; track how many secrets testers find unaided. |
