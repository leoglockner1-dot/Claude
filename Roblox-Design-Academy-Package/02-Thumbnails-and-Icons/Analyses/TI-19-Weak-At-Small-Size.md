## Observed
| Game | Problem at 64 px |
|---|---|
| Fisch | Dark green, busy scene (creature, character, effects); no single shape |
| Violence District | Dark brown-red with a blurred figure: mood without a readable subject |
| Bloodlines | Sepia, low contrast; the anime character blends into the background |
| Clone Baby Care | Pale small figures on a dark background; the subject is too small |
| Anime Dice | Big text "1 in 9,342,584" plus a character plus effects; the digits turn to noise |

## Note
Several are **very successful games**. Weak icon legibility clearly doesn't prevent success when a game has momentum (an established audience, word of mouth, YouTube). The lesson is about **new** games, which lack those advantages.

## Fix pattern
Crop to one subject, raise value contrast, drop the text, and test at 64 px in a grid (see [TI-17](TI-17-Small-Size-Champions.md)).

## Original application
Crop tighter, raise contrast, remove text.
