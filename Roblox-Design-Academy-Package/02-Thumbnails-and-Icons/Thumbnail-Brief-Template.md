# Thumbnail Brief Template (original key-art brief)

Use before producing any thumbnail. Fill every field; a field you cannot fill is a design problem.

```
GAME:                     GENRE:
ONE-LINE PROMISE: "A game where you ______ to ______."
VERB SHOWN:               STAKES / ASPIRATION SHOWN:
PLAYER FANTASY (who am I?):
SUBJECT (one):            SECONDARY (optional, one):
CAMERA: angle __, lens/FOV __, distance __
LIGHT: key light source __ (motivated by __), accent colour __
PALETTE ROLES: dominant __ / secondary __ / accent (focal only) __
COMPOSITION: diagonal or centred? eye path: __ → __ → __
TEXT: none | ≤3 words: "__"  (never bottom band)
AUTHENTICITY: which real in-game moment/assets? __
DISTINCTIVENESS: which 3 competitors will sit next to it? how is ours different?
VARIANTS FOR PERSONALIZATION: A __ / B __ / C __
SMALL-SIZE TEST RESULT (320×180): __
```

## Example (original)
- Promise: "A game where you **ferry passengers across a stormy lake** to **upgrade your boat into a steamship**."
- Verb: steering through a wave; stakes: lightning striking near the bow; aspiration: a steamship silhouette in the distance.
- Camera: low, 3/4 from the bow; key light: lightning flash; accent: lantern yellow.
