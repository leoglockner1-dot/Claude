# CL-06 — First-Session / Onboarding

Mark each item ✅ verified (write how), ❌ failed (write what), ⬜ not checked. **Never tick an item you did not check.** Distinguish verified results from assumptions in the report.

- [ ] Spawn faces first interactable + landmark
- [ ] Core verb taught first, through play (ONB-001)
- [ ] Rules shown as pictures, ≤3 words captions (ONB-002)
- [ ] Guidance points at targets (ONB-003); arrows large
- [ ] Screen never blurred/blocked without one-line reason (ONB-004)
- [ ] Secondary systems contextual (ONB-005)
- [ ] Timed hints only for stuck players, once (ONB-006)
- [ ] Every step logged as funnel step (ONB-007)
- [ ] First reward within the first minutes; travels to counter
- [ ] First upgrade visibly changes something
- [ ] Ends with moment of joy + visible next goals (ONB-008)
- [ ] Tested with 5 first-time players; recorded where each hesitated
