# CL-11 — Final Quality Gate

Mark each item ✅ verified (write how), ❌ failed (write what), ⬜ not checked. **Never tick an item you did not check.** Distinguish verified results from assumptions in the report.

- [ ] CL-01…CL-10 completed; unverified items listed explicitly
- [ ] Design critique checklist run on UI, thumbnail, icon, one VFX, one reward sequence
- [ ] Identity statement visible across 3 random screens (crop test)
- [ ] Two academy references compared per area; differences written
- [ ] Real-device playtest recorded
- [ ] Funnel baseline captured before launch
- [ ] Lessons written to the vault's lessons folder
