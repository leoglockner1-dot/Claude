# Typography, Colour and Spacing

## Typography
- ≤2 families, 4–5 sizes; display font only for titles/numbers (UI-002; UI-04, UI-11 counter-examples, UI-09 positive).
- Strokes only where text sits over the 3D world (UI-007; UI-25).
- Keywords in colour with `RichText` (V26).
- Builder Sans/Extended/Mono are Roblox fonts licensed for use (docs license page).

## Colour
- Palette roles: surface, text, accent (one), success, warning, danger, currencies, rarities, disabled.
- Neutral chrome, saturated content (UI-003; UI-26 positive, UI-15 negative).
- Semantic map fixed early: health green etc. (UI-11, UI-07).
- Test greyscale; never colour alone (UI-012).

## Spacing
- Base unit 4 or 8; only multiples (UI-004; UI-23 critique "different everywhere").
- Optical alignment for icons; equal internal padding in cards.

## Hierarchy test
NN/g's **squint test**: blur the screen — the primary action must remain the most visible element ([source](../22-Source-Library/External-Design-Sources.md)).
