# First-Session Design

## Roblox guidance (verified)
FTUE success = Day-1 retention + onboarding goals: **teach the essentials, get to the fun quickly, leave players wanting more** (short/mid/long goals; moments of joy). Techniques: visual elements, contextual tutorials, timed hints; A/B test steps with Experiments; tune values with Configs.

## Evidence in this academy
| Technique | Positive | Negative |
|---|---|---|
| Picture rules | ONB-02, UI-22 | text walls |
| Point at target | ONB-03, ONB-01 | tiny step chip (UI-25) |
| Contextual tutorials | ONB-04 | forced shop step (ONB-06) |
| Timed hints | ONB-05 | — |
| Feedback layering | GF-01 | silent upgrade (V12) |
