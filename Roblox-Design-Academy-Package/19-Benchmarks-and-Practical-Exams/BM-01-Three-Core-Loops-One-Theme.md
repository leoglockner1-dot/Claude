# BM-01 — Three core loops for one theme

| Field | Value |
|---|---|
| Area | Game design |
| Level | Intermediate |
| Time box | 90 min |
| Status | ✅ Executed by the academy |

## Task
Given one theme, design three core loops that feel different (different core feeling, decision type and session shape). Fill all 15 fields of the [Core Loop Evaluation Framework](../03-Core-Gameplay-Loops/Core-Loop-Evaluation-Framework.md) for each, then recommend one to prototype.

## Inputs
- A theme (the worked answer uses "a volcano island").
- The framework template.

## Deliverables
- Three 15-field sheets.
- A comparison table (feeling, decision, session, social, biggest risk, prototype cost).
- A recommendation with the reason.

## Acceptance criteria (pass/fail)
- [ ] All 15 fields filled for each concept, none with "TBD".
- [ ] The three concepts differ in at least 3 of: core feeling, decision type, session length, social mode.
- [ ] Each concept names a boredom point and a falsifiable failure criterion.
- [ ] The first-session field gives timings (0–10 s, 10–30 s, first reward).
- [ ] Every claim is marked [HYP] until playtested.

## Scoring rubric (0 / 1–2 / 3)
| Dimension | 0 | 1–2 | 3 |
|---|---|---|---|
| Distinctness | Three reskins of one loop | Two differ | All three differ on ≥ 3 axes |
| Falsifiability | Success = "fun" | Some measurable criteria | Every concept has numeric success and failure criteria |
| First minute | Vague | Steps without timings | Timed steps, a reward before 90 s |

## Common failure modes
- The theme dictates the loop: three collection games with different skins.
- Meta loop listed as "pets, rebirths, codes" with no link to the core verb.
- Failure criteria that cannot fail.

## Self-critique before submitting
Run the [Self-Critique Loop](../18-Skill-Training/Self-Critique-Loop.md): state the criteria **before** looking at the result, inspect the output (not your intention), and log every failed version.
