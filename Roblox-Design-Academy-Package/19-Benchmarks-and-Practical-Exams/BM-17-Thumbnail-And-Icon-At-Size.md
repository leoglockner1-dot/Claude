# BM-17 — Thumbnail and icon that read at store size

| Field | Value |
|---|---|
| Area | Thumbnails / marketing |
| Level | Intermediate |
| Time box | 2 h |
| Status | ☐ Specification only (not executed) |

## Task
Design an icon and a 16:9 thumbnail for one Core Loop Library concept; test readability at the smallest sizes shown in the Roblox UI and against 5 live-chart competitors in the same genre.

## Inputs
- [R08](../18-Skill-Training/Design-Recipes/R08-Strong-Thumbnail-Composition.md), [R09](../18-Skill-Training/Design-Recipes/R09-Recognizable-Game-Icon.md)
- [Live Chart Study](../02-Thumbnails-and-Icons/Live-Chart-Study-2026-10.md)

## Deliverables
- Icon + thumbnail, a side-by-side grid at small size with 5 genre competitors, a written critique.

## Acceptance criteria (pass/fail)
- [ ] One focal subject, readable at the smallest size.
- [ ] Does not imitate a competitor's character, layout or branding.
- [ ] Passes [CL-02](../23-Quality-Checklists/CL-02-Thumbnail-and-Icon-Review.md).

## Scoring rubric (0 / 1–2 / 3)
| Dimension | 0 | 1–2 | 3 |
|---|---|---|---|
| Read at size | No | Partly | Yes |
| Distinctness in grid | Blends in | — | Stands out |
| Originality | Imitative | Generic | Original |

## Common failure modes
- Text that is unreadable at icon size.
- Copying the genre leader's composition.

## Self-critique before submitting
Run the [Self-Critique Loop](../18-Skill-Training/Self-Critique-Loop.md): state the criteria **before** looking at the result, inspect the output (not your intention), and log every failed version.
