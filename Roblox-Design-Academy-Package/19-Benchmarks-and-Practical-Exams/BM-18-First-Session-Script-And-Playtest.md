# BM-18 — First-session script and fresh-player playtest

| Field | Value |
|---|---|
| Area | Onboarding |
| Level | Advanced |
| Time box | 1 day |
| Status | ☐ Specification only (not executed) |

## Task
Write a timed first-session script (0–10 s, 10–30 s, 60–90 s, 3–5 min) for a prototype and playtest it with ≥ 5 players who have never seen it, recording time-to-first-action and drop-off.

## Inputs
- [CL-06 First Session](../23-Quality-Checklists/CL-06-First-Session-Onboarding.md)
- [R10 Short Onboarding](../18-Skill-Training/Design-Recipes/R10-Short-Onboarding-Sequence.md)

## Deliverables
- The script, raw playtest notes, a table of timings per tester, and changes made.

## Acceptance criteria (pass/fail)
- [ ] ≥ 5 fresh testers.
- [ ] Median time to first core action ≤ 30 s, or a documented fix and re-test.
- [ ] Observations separated from interpretations.

## Scoring rubric (0 / 1–2 / 3)
| Dimension | 0 | 1–2 | 3 |
|---|---|---|---|
| Script precision | Vague | Steps | Timed steps |
| Test validity | Friends who know the game | Mixed | Fresh players |
| Follow-through | No changes | Changes | Changes re-tested |

## Common failure modes
- Testing with people who already know the game (FC-GD-06 pattern).

## Self-critique before submitting
Run the [Self-Critique Loop](../18-Skill-Training/Self-Critique-Loop.md): state the criteria **before** looking at the result, inspect the output (not your intention), and log every failed version.

## Academy run and evidence
**Not executed**: this needs a running game and human testers, which this environment does not have. The Core Loop Library's field 9 provides first-session scripts with no playtest.
