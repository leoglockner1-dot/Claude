# R14 — Coherent visual identity system

## 1. Goal
Produce a small, enforceable identity system used by world, UI, VFX, audio and marketing.

## 2. When to use
Project start or rebrand.

## 3. Required inputs
Game premise, target audience, emotional target.

## 4. Recommended structure
Identity statement (5 lines) → token set (Style Editor + palette module) → component kit (panel, button, card, icon frame) → VFX colour/shape table → audio timbre palette → marketing rule (subject + grade).

## 5. Step-by-step implementation
1. Write the identity statement (Visual Identity Framework).
2. Make 3 style frames (menu, HUD in action, shop) before production.
3. Run crop/squint/genre tests on the frames.
4. Encode tokens; build components; forbid raw colours in code review.
5. Write the marketing rule (e.g., "one red mannequin + one weapon" style rule of your own).

## 6. Animation guidance
Define motion personality (snappy vs floaty) once — durations/easing tokens.

## 7. Sound guidance
Define timbre palette (e.g., wooden/organic vs synthetic).

## 8. Mobile considerations
Style frames must include a phone frame.

## 9. Performance considerations
Prefer built-in materials; one 9-slice set for UI.

## 10. Common mistakes
Picking styles per screen; copying a competitor's skin; template defaults.

## 11. QA checklist
- [ ] Statement written
- [ ] Tokens enforced
- [ ] Crop test passes on 3 random screens
