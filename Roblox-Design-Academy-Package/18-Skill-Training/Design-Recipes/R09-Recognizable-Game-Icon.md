# R09 — Recognizable game icon

## 1. Goal
An icon recognisable at 64 px and distinct from genre neighbours.

## 2. When to use
Launch; rebrands.

## 3. Required inputs
Main character/object; palette; brand mark (if established).

## 4. Recommended structure
One face or bold object filling 60–100 % of the square; high value contrast; ≤1 short wordmark; background simple gradient or flat colour.

## 5. Step-by-step implementation
1. Pick the most recognisable element of the key art (often the thumbnail subject's face).
2. Render/crop at 1024×1024, export 512×512+.
3. Test at 150 and 64 px in a grid of 20 genre competitors.
4. Check silhouette and greyscale.
5. Plan event variants that keep the subject (frames with margin).
