# CS-17 — Outbreak Mayhem (DevForum: feature-rich but unclear)

> Source: <https://devforum.roblox.com/t/outbreak-mayhem-feedback-wanted/4849015> (2026-09-04).

## Observed
- Developer lists many features: weapons, classes, extras, emotes, products, discovery UI, zombie classes, 2 game modes, 5+ maps.
- Thread: **64 % likes**; reviewer: "I'm not really sure I grasped the point of the game fully … both of these game plans basically means you're still looking for guns in lockers"; lobby and shop "boring".
- Update: "objective mode is now very straight forward and very sightreadable, the physical store within the lobby has been added".

![Outbreak Mayhem key art](../Assets/UI/devforum/df-4849015-01.jpg)

## Lessons
- Feature count ≠ clarity (LOOP-004): many systems, unclear core.
- "Sight-readable" objectives were the developer's fix.

## Confidence
Medium.
