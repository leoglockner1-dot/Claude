# Roblox Design Academy — Overview

**Purpose:** improve the design judgment of anyone (human or Claude agent) building Roblox games — gameplay, UI, thumbnails, icons, animation, VFX, audio, progression, onboarding, identity and technical implementation — with traceable evidence instead of generic advice.

## How to use it (for a Claude agent building a game)
1. **Before work on a feature**, open the matching principles file in `14-Design-Principles/` and the topic note; read 2 referenced analyses.
2. **Write acceptance criteria** using the relevant checklist in `18-Checklists/`.
3. **Implement** using a recipe in `13-Reusable-Design-Recipes/` and the facts in `11-Roblox-Technical-Reference/`.
4. **Critique** with `12-Anti-Patterns-and-Design-Critique/Design-Critique-Checklist.md` — write weaknesses first.
5. **Record** what you learned in the vault (lessons folder of the existing academy).
