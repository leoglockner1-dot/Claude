## What appears to work
- Long-running (2017) with constant events (Halloween "Where Bear? Returns", sticker packs).
- Icon: cute dragon face close-up + wordmark — reads at 64 px ([TI-17](../02-Thumbnails-and-Icons/Analyses/TI-17-Small-Size-Champions.md)).

## Risks, weaknesses or open questions
- Event-specific multipliers are time-pressure monetization; acceptable if clearly optional (opinion).

## Lessons for our games
- Events re-use the same core (care/collect/trade) with new content — LOOP-003/LOOP-007.

## Original application
A plant-care game where seasonal events add new seed varieties and a server-wide hunt, but the core stays watering/growing/trading.
