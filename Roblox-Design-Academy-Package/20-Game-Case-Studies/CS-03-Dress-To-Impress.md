## Loop breakdown (inferred)
| Layer | Inference |
|---|---|
| Minute-to-minute | Browse items, compose an outfit within a theme |
| Most repeated action | Strut the runway, pose, vote on others (description) |
| Progression engine | Become "TOP MODEL", new items, quests (name tag "NEW QUEST") |
| Social loop | Voting on outfits = players judge players |
| Monetization | 14 passes 129–799 R$: item sets, Custom Makeup, Materials+, x2 Money, VIP, Run Faster, Increased Item Limit; Roblox docs cite **intermission theme props** as an in-play contextual purchase |

## What appears to work
- Players are content for each other (SOCIAL-004): the runway + voting turns expression into competition.
- Premium, non-cartoon thumbnail art style distinct in the grid ([TI-13](../02-Thumbnails-and-Icons/Analyses/TI-13-Dress-To-Impress-Thumbnail-Set.md)).
- Monetization is mostly expression (sets, makeup) — aligns with the fantasy.

## Risks, weaknesses or open questions
- Thumbnail set hygiene issues (duplicate, off-season).

## Lessons for our games
- A judging/voting loop needs no complex AI or content — players supply it.

## Original application
A cake-decorating contest: themed rounds, 3-minute build, everyone votes with stars; winning cakes displayed in a lobby gallery.

## Confidence
Medium.
