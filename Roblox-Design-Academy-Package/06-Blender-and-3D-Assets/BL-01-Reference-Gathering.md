# BL-01 — Reference gathering for 3D assets

## Purpose
Build an asset from understanding, not memory: know which features make the object recognizable, what the game's style allows, and what to avoid copying.

## Procedure
1. **Write the brief:** object, gameplay role (pickup, obstacle, decoration, tool), viewing distance and camera angle, art direction, poly budget, pivot, collision needs.
2. **Collect 3 kinds of reference** (6–12 images in total):
   - **Real-world/function:** how the object is built (hinges, joints, materials). This gives believability even in stylized art.
   - **Style:** 2–4 assets from games or artists in the *target style*, for bevel size, saturation and proportion exaggeration. Use these for principles only; never trace another game's distinctive asset.
   - **Context:** the environment it sits in, to check value and colour contrast.
3. **Extract the read:** list the 2–3 features that make the object identifiable. For a chest: the lid shape (arched or flat), bands or trim, and a lock as the focal point. Everything else is optional.
4. **Decide what to exaggerate** for the style (toy: thickness and roundness; cartoon: taper, bulge and the open state; premium: crisp edges and trim detail).
5. **Make a reference board** (a PureRef/Blender image-empty collage or a simple grid image) and keep it with the source file. Record each image's source URL and licence.

## Originality rules
- Combine features from several references. Do not reproduce one design.
- Avoid IP-recognizable shapes, logos and character likenesses ([TI-27 IP-adjacent imagery](../02-Thumbnails-and-Icons/Analyses/TI-27-IP-Adjacent-Imagery-Risk.md)).
- If a reference is copyrighted, use it for study only; do not include it in shipped textures.

## Acceptance criteria
The brief exists; the 2–3 identifying features are named; style references are cited; the final asset passes the silhouette test ([BL-02](BL-02-Shape-Language-Silhouette-Proportion.md)).

## Example
[BL-EX-04 Treasure chests](Exercises/BL-EX-04-Treasure-Chests.md) used "arched or domed lid + bands/trim + lock" as identifying features. The v1 premium chest dropped the arched lid and immediately read as a crate. That evidence shows why step 3 matters.
