# CL-08 — Shop & Monetization Ethics

Mark each item ✅ verified (write how), ❌ failed (write what), ⬜ not checked. **Never tick an item you did not check.** Distinguish verified results from assumptions in the report.

- [ ] Core loop fully playable and fair without paying (PROG-007)
- [ ] No pay-to-win in competitive modes
- [ ] Paid random items: all outcomes + % odds (sum 100 %) before purchase, labelled button (PROG-005)
- [ ] Marketing numbers match odds
- [ ] No purchase prompts during active play; one modal at a time (PROG-008)
- [ ] Robux buttons visually distinct from soft currency
- [ ] No fake discounts or permanent "limited" timers
- [ ] Private servers not priced to block friends (Roblox guidance)
- [ ] Purchases granted via ProcessReceipt; idempotent
- [ ] Prices reviewed against market context (study) and audience
