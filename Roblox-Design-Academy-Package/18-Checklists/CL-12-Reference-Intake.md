# CL-12 — Reference Intake (adding new evidence)

Mark each item ✅ verified (write how), ❌ failed (write what), ⬜ not checked. **Never tick an item you did not check.** Distinguish verified results from assumptions in the report.

- [ ] Source URL and access date recorded
- [ ] Asset saved with descriptive filename in the right Assets folder (or link only if copying is inappropriate)
- [ ] Analysis written with the template (observable / works / why / doesn't / principles / implementation / original application / confidence)
- [ ] Observations separated from interpretations
- [ ] Linked to ≥1 principle and topic note
- [ ] Video: timestamps recorded; audio marked as listened or not
- [ ] Manifest updated
- [ ] No fabricated or AI-generated "screenshots" presented as real
