# CL-03 — Animation & VFX Review

Mark each item ✅ verified (write how), ❌ failed (write what), ⬜ not checked. **Never tick an item you did not check.** Distinguish verified results from assumptions in the report.

- [ ] Each effect has a trigger and the player question it answers
- [ ] Frequent-action feedback ≤0.3 s (measured from a recording)
- [ ] Anticipation exists for hazards/attacks (FEEL-001)
- [ ] Eased curves for organic motion (FEEL-003)
- [ ] Repeated effects readable at max rate (FEEL-004)
- [ ] Intensity tier matches importance (FEEL-006)
- [ ] Play space readable at the largest effect (screenshot at peak)
- [ ] Particle shapes/colours semantic (FEEL-005)
- [ ] Mobile particle rates ≤100/s per emitter; tested on baseline phone
- [ ] ReducedMotion reduces shake/zoom/tweens
- [ ] Long sequences skippable after first view
- [ ] Teleports masked by fades (FEEL-010)
