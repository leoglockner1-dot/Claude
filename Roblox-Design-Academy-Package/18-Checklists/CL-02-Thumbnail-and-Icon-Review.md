# CL-02 — Thumbnail & Icon Review

Mark each item ✅ verified (write how), ❌ failed (write what), ⬜ not checked. **Never tick an item you did not check.** Distinguish verified results from assumptions in the report.

- [ ] 1920×1080, 16:9, no compression artefacts
- [ ] Brief completed (verb, stakes, subject, accent)
- [ ] Stranger completes "a game where you ___" in 1 s
- [ ] One focal point (blur test); silhouette readable
- [ ] Nothing essential in the bottom band
- [ ] In-engine visuals; no fake UI; no claims/ads
- [ ] ≤3–4 words of text or none
- [ ] Distinct next to 10 genre competitors at 320×180
- [ ] Consistent with the game's visual rule and other thumbnails
- [ ] 2–5 variants active; no duplicates; no off-season art
- [ ] Logged-out detail page shows all images (no placeholders)
- [ ] Numbers/odds claims identical across name, icon, thumbnails and in-game
- [ ] Icon: ≥512 px square; tested at 150 px and 64 px; one subject; no stickers; not default
- [ ] Icon still recognisable if an event frame/countdown is added
