# CL-04 — Core Loop Review

Mark each item ✅ verified (write how), ❌ failed (write what), ⬜ not checked. **Never tick an item you did not check.** Distinguish verified results from assumptions in the report.

- [ ] Three layers written (minute-to-minute, repeated action, progression engine)
- [ ] Main/supporting/meta/social/monetization loops mapped
- [ ] New tester performs core verb within ~60 s without help (timed)
- [ ] Tester can explain what to do and why after one cycle
- [ ] Each cycle has visible stakes or aspiration (LOOP-005)
- [ ] Every system maps to a loop step; orphans removed (LOOP-004)
- [ ] Depth via new contexts for the verb, not new systems (LOOP-003)
- [ ] Short complete sessions possible (LOOP-006)
- [ ] Solo player can complete the loop (SOCIAL-003)
- [ ] Funnel instrumentation per step (LOOP-008)
