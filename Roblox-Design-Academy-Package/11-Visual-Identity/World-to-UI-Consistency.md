# World-to-UI Consistency

- UI materials should echo world materials (wood signage for a farm, holograms for a station — V25).
- Tone mismatch confuses genre (UI-20: horror street + teal sci-fi panels).
- Diegetic UI for flavour, screen UI for critical state (V25).
- One semantic colour map shared by UI, VFX and world signals (health green in bar, particles, pickup beam — V13).
