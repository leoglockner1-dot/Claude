# Visual Identity Framework

A framework that does **not** prescribe a style. Fill it per game; every later asset is checked against it.

## 1. Identity statement (5 lines)
1. Emotional target (3 words): e.g. "tense, hunted, curious".
2. Shape motif: one geometric/organic motif for UI + props (ID-002; BotClash chamfers, tilted cards UI-22).
3. Palette roles: dominant / secondary / **one accent** + fixed semantic colours (ID-006, UI-003).
4. Type pairing: one display + one reading face (ID-004).
5. Reference board: 3–5 references with the **principle** taken from each (ID-005).

## 2. Consistency map
| Layer | Must express the identity via |
|---|---|
| World | materials, lighting grade, silhouettes |
| UI | motif, palette roles, type, icon family |
| VFX | colour semantics, shapes, intensity tiers |
| Audio | timbre palette (bright/dark, organic/synthetic) |
| Marketing | same grade + subject rule as the game (TI-08) |

## 3. Tests
- Crop test: would a 10 % crop of any screen be recognisable as this game?
- Squint test for hierarchy; greyscale test for value.
- Genre test: does a stranger guess the right genre from one screenshot? (UI-20 tone mismatch counter-example)
