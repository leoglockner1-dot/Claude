# First-Minute Timeline (design template)

A template to script the first 60–120 seconds. Values are **targets/hypotheses**, to be verified with funnels.

| t | Player experiences | Design tools | Measure (funnel step) |
|---|---|---|---|
| 0–3 s | Spawn facing the first interactable; world shows the goal (landmark) | Camera orientation, beacon (LEVEL-002) | Spawned |
| 3–10 s | Understands what to do without reading | Picture sign (ONB-002), arrow/trail (ONB-003) | First movement toward goal |
| 10–30 s | Performs the core verb | Big obvious target, input hint for current device | First core action |
| 30–60 s | Receives first reward, sees it travel to a counter | R03 currency collection | First reward |
| 60–120 s | Spends reward on a visible upgrade | R04 upgrade interaction | First upgrade |
| 2–5 min | Meets others / first social moment | Shared goal, emote prompt | First social action |
| End | Moment of joy + next goals visible | R06 milestone | Onboarding complete |

Counter-evidence: a forced shop step at second 0 lost 48 % of users ([ONB-06](../13-Onboarding-and-Multiplayer/Onboarding/Analyses/ONB-06-DevForum-Forced-Blur-Tutorial-Funnel.md)).
