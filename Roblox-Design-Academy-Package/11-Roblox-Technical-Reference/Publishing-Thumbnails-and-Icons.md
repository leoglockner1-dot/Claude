# Publishing: Thumbnails and Icons

> **Verified** against the Roblox Creator Docs (GitHub mirror commit 4e795e6 and create.roblox.com, accessed 2026-10-24). Re-check yearly. Items marked *(recommendation)* are design advice, not engine facts.

**Thumbnails** [docs](https://create.roblox.com/docs/production/publishing/thumbnails): 16:9, ideally 1920×1080 (other ratios stretched); up to 10 images/videos; formats jpg/gif/png/tga/bmp; videos: 3 uploads/month quota, not supported on Xbox/PlayStation/VR, must be authentic (no misrepresented gameplay, artificial visuals, external footage, voice-over/lyrics, ads/claims); allowed: camera work, minor post, logo overlay, curated sequences, in-game UI text, catalog music. Personalization starts with ≥2 active thumbnails (activate 2–5; <3 MB); Roblox reports +8.5 % average qualified play-through rate in testing. Keep essential content out of the bottom area. Freecam: Shift+P in solo playtest.

**Icons** [docs](https://create.roblox.com/docs/production/publishing/experience-icons): square ≥512×512; displayed down to ~150×150; one per locale; moderated; default icon is a documented bad example.
