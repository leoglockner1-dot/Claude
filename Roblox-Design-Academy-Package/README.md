# Roblox Design Academy — Portable Obsidian Package

A researched, evidence-linked knowledge base for designing better Roblox games: UI/UX, thumbnails and icons, core loops, progression and economy, animation and game feel, sound, visual identity, level design, onboarding, multiplayer, and Roblox technical constraints.

**Built:** 2026-10-24 by a Claude Code research session. **Self-contained:** relative links only; all images, video clips and analysis sheets are inside `Assets/`.

## Start here
1. `00-Start-Here/Academy-Overview.md` — purpose and how to use it
2. `00-Start-Here/Research-Limitations.md` — what this research could and could not see
3. `00-Start-Here/Master-Index.md` — every note, plus "find by question"

## What's inside (actual counts)
See `MANIFEST.md` for the full inventory. Summary:
- 210 Markdown files: 206 notes in numbered folders (incl. galleries and indexes) + 4 root documents
- 64 reference analyses: 26 UI, 30 thumbnail/icon, 6 onboarding, 1 level design, 1 game feel
- 19 video-analysis notes covering 29 official Roblox videos (timing and audio measured)
- 18 game case studies; 85 live games in the chart study plus ~30 more games from Roblox docs and the DevForum
- 94 design principles; 15 recipes; 12 checklists plus a design-critique checklist; 28 anti-patterns
- 367 asset files (images, 29 video clips, analysis sheets) with sources in `Assets/asset-registry.json`
