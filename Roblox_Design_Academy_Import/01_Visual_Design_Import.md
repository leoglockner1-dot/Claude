## Identity statement (write one per game before any UI or art) [GEN/HYP method]
Every project gets a five-line identity statement in its project note:
1. **Emotional target**: e.g., "cozy, curious, safe" or "tense, hunted".
2. **Shape motif**: one geometric motif used across UI and props (chamfer, pill, hexagon, brush stroke, stitched fabric…) [OBS IMP-08].
3. **Palette**:
   - 1 dominant + 1 secondary + 1 accent (the accent is for primary actions and focal points only)
   - plus the fixed semantic colours (health, currency, rarities)
4. **Type pairing**: one display font and one readable font.
5. **Reference board**: 3–5 academy references, with a note on what to take from each (the principle, never the look).

Generic output usually means one of these five decisions was never made.

## Principles
- **Value (light/dark) before hue.** A design that reads in greyscale reads everywhere. Check UI and key art in greyscale [GEN].
- **Saturation is energy; hue is mood; contrast is intensity.** Proven by the same icon in three grades → three genres [OBS IMP-28].
- **One accent, used sparingly.** It marks the focal point or primary action. If it's everywhere, it marks nothing [OBS IMP-25, IMP-08].
- **Shape language carries tone.** Round = friendly or toy-like ([IMP-01](06_Reference_Analyses/IMP-01_Spellbound_RPG_Contextual_Radial_Menu.md)); angular or chamfered = tech or competitive ([IMP-08](06_Reference_Analyses/IMP-08_BotClash_Inventory_Master_Detail.md)); hand-drawn = personal or improvised ([IMP-16](06_Reference_Analyses/IMP-16_Color_or_Die_Rules_Sign.md)) [GEN + OBS].
- **Silhouette first.** Characters, items and icons must be recognisable as solid black shapes [GEN].
- **The world teaches.** Signs, trails, footprints and lighting guide players better than UI text ([IMP-16](06_Reference_Analyses/IMP-16_Color_or_Die_Rules_Sign.md), [IMP-18](06_Reference_Analyses/IMP-18_Jailbreak_Footprint_Hint.md), [IMP-15](06_Reference_Analyses/IMP-15_Creatures_of_Sonaria_Guided_Trail.md)) [RBX].
- **Fun beats fidelity** for much of the audience. Younger players are "less sensitive to visual fidelity". Polish what is touched most: core actions, HUD, first five minutes [RBX].
- **Performance is part of the visual design.** Mobile memory is limited; prefer built-in materials, reuse meshes and textures, and avoid partial transparency [FACT].
- **Honesty:** marketing art must match in-game visuals, because the video rules reject artificially enhanced graphics [FACT].
