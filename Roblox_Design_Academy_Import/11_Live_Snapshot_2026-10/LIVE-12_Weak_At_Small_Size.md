# Reference LIVE-12 — Icons That Struggle at 64 px

## Metadata
- Category: Icons / Bad-ish examples
- Source: Fisch (5750914919), Violence District (6739698191), Bloodlines (1946714362), Clone Baby Care (10770018231), Anime Dice (10708913337)
- Asset: `../Assets/Icons/LIVE/<universeId>.jpg`; grid `../Assets/Thumbnails/LIVE/_sheets/icons64.jpg`
- Date added: 2026-10-24 (snapshot: Halloween week)
- Rating: 2/5 for small-size legibility (these may be strong at full size)
- Confidence: Medium. Legibility is partly subjective. Viewed on a dark grid.
- Reference type: Mixed (negative for small-size readability)

## Observed
| Game | Problem at 64 px |
|---|---|
| Fisch | Dark green, busy scene (creature, character, effects); no single shape |
| Violence District | Dark brown-red with a blurred figure: mood without a readable subject |
| Bloodlines | Sepia, low contrast; the anime character blends into the background |
| Clone Baby Care | Pale small figures on a dark background; the subject is too small |
| Anime Dice | Big text "1 in 9,342,584" plus a character plus effects; the digits turn to noise |

## Note
Several are **very successful games**. Weak icon legibility clearly doesn't prevent success when a game has momentum (an established audience, word of mouth, YouTube). The lesson is about **new** games, which lack those advantages.

## Fix pattern
Crop to one subject, raise value contrast, drop the text, and test at 64 px in a grid (see [LIVE-10](LIVE-10_Small_Size_Champions.md)).
